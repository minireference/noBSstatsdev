Frequently Asked Questions

Is this a theory book or a practical book?

It’s a practical book. It explains the probability behind statistical inference and uses formulas where they help you understand how a procedure works.

Is this a coding book?

The focus is statistics. Python examples show the steps behind statistical procedures so you can read and run the code alongside the explanations and formulas.

What can I learn for free?

The tutorials and computational notebooks are free. Each notebook combines explanations, math, and runnable code that you can follow independently of the book.

Is this a Bayesian or a frequentist book?

The book covers both perspectives. Chapters 3 and 4 introduce classical (frequentist) statistics and linear models. Chapter 5 revisits the same topics from a Bayesian perspective.

What math do I need to know?

High school algebra and basic functions are enough to get started. Part 1 builds the data and probability foundations you’ll use for statistical inference in Part 2.
